# セキュリティ対策と検証範囲

このアプリは写真・MCID・アルバムを公開閲覧する用途です。非公開写真の保管やユーザーごとのアクセス制限は行いません。「絶対に侵入されない」という保証はできませんが、次の対策を実装しています。

## アプリ

- 初回設定はランダムな使い捨てコードが必須。設定は排他制御し、設定済みの管理者を初回APIで上書きできません。
- 管理者パスワードはWerkzeugのscryptで保存。セッション鍵はランダム生成・永続化。HttpOnly / SameSite=Strictと、公開HTTPSでSecure Cookieを使用します。
- 書き込みAPIはサーバー側の認証・CSRFチェック、Originチェックを実施します。ログインは全体で5分間10回までです。この制限のため攻撃者による一時的なログイン妨害は残り得るので、Cloudflare側のレート制限も併用してください。
- SQLは値をパラメーター化。画像名・MCIDはHTMLとして挿入せず文字列として描画。CSP・クリックジャッキング対策・MIMEスニッフィング防止を設定します。
- `PUBLIC_URL` 設定時は受信HostとOriginを検証。転送ヘッダーを信頼する構成では、NPM以外が直接アクセスできないようにします。
- 管理用JSONリクエストは16KiB（一括操作は64KiB・500枚まで）、画像アップロードはリクエスト全体で20MiB、multipartは4パートまで。画像デコーダーはPNG/JPEG/WebPに限定し、1200万画素以内で画像本体も検証します。画像は再エンコードし、EXIF等のメタデータを引き継ぎません。
- メディア以外のデータディレクトリは配信しません。非表示画像は公開ルートで404を返し、管理者だけが `/api/media/*` から閲覧できます。認証API・標準ログインフォームの送信先 `/auth/*`・管理用一覧・管理者向け画像は `private, no-store` です。
- 管理者向けの任意URL取得・シェル実行機能はありません。

## コンテナ

非rootユーザー、読み取り専用のルートFS、全Linux capabilityの削除、権限昇格禁止を指定しています。Dockerソケットやホストのルートをマウントせず、書き込み先は画像・DB・設定用ボリューム（画像は指定した保存先への変更も可能）と一時領域だけです。メモリ768MiB、CPU 1コア相当、プロセス128個、一時領域128MiBに制限します。これにより異常時の影響を限定しますが、カーネルの脆弱性からホストを完全に隔離する保証ではありません。

認証済みの管理者は継続して画像を追加できるため、永続ディスクの容量監視・バックアップは別途必要です。ホストOS、Docker、NPM、Cloudflareの設定も更新・管理してください。

## 依存関係と継続的な検証

本番依存を `requirements.lock`、テスト依存を `requirements-dev.lock` に分離しています。テストツールは本番Dockerイメージに含めません。更新後に機能テストと依存関係監査を実行します。

```sh
.venv/bin/pip install -r requirements-dev.lock
.venv/bin/python -m pytest -q
# 監査ツールは開発環境にだけ追加
.venv/bin/pip install pip-audit
.venv/bin/pip-audit --disable-pip --no-deps -r requirements-dev.lock
```

監査の「該当なし」は、その時点のデータベースに登録されたPython依存の既知の問題が検出されなかったという意味です。未知の脆弱性、ホストOS、Dockerベースイメージの全OSパッケージ、実際の公開先ネットワークへの侵入試験をカバーしません。ベースイメージも定期的に `docker compose build --pull` で更新してください。

## 今回の確認結果

Flask 3.1.3、Pillow 13.0.0、pytest 9.0.3へ更新しました。更新後の本番・開発依存に対するpip-auditでは登録済み脆弱性は検出されませんでした。認証・CSRF・画像の検証、アルバム統合・改名・削除、非表示アクセス制御、既存DBの移行、画像保存先の変更を自動テストしています。公開先のNPM・Cloudflare・自宅サーバーの設定を直接検査した結果ではありません。

管理者パスワードの変更はサーバー端末の `manage.py reset-password` から実施し、全ワーカーで即時に読み直します。パスワードの版をセッションと照合し、変更前のログインを失効させます。パスワードのコマンドライン引数受け取りやWeb経由の無認証リセットはありません。
